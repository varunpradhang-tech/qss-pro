# Store Listing Draft

## App Name

QSS Pro: Quantity Surveying Software

## Short Description

Civil quantity takeoff from grid-dimensioned structural and architectural drawings.

## Full Description

QSS Pro helps civil engineers, quantity surveyors, contractors, and estimators calculate civil work quantities from properly prepared PDF, DXF, or CAD-based drawings.

Upload drawings that already contain grid lines and grid-to-grid dimensions in both X and Y directions. The app is designed to read drawing dimensions and calculate quantities using rule-based measurement logic aligned with IS code mode of measurement.

Structural quantity modules include raft, column, beam, and slab quantities for concrete, shuttering, and steel BBS.

Architectural quantity modules include brickwork/blockwork, plaster, paint, and flooring.

Free users can view total quantity results. Premium users can export detailed member-wise Excel-compatible quantity sheets with length, breadth, height, diameter, spacing, number, openings, calculated quantity, and measurement basis.

## Key Features

- Structural quantity takeoff for raft, column, beam, and slab
- Concrete, shuttering, and steel BBS quantity rules
- Architectural quantity takeoff for brickwork, plaster, paint, and flooring
- IS code mode of measurement basis
- Total quantity view for free users
- Premium member-wise Excel CSV export
- Drawing preparation workflow based on marked grids and dimensions
